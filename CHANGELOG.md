# Changelog

## 1.1.0 — 2026-10-01

- Added chronological final-period holdout evaluation.
- Added majority-class and persistence baselines.
- Added API readiness and model-info endpoints.
- Added model/version metadata to prediction responses.
- Added pre-commit configuration, GitHub issue/PR templates and CODEOWNERS.
- Removed unnecessary Git LFS filters because packaged artifacts are small enough for normal Git history.
- Tightened artifact metadata and serving boundaries.

## 1.0.0 — 2026-10-01

- Repackaged the field-project ML work as a reusable Python package.
- Added group-aware supervised validation.
- Added FastAPI scoring endpoint.
- Added deterministic training pipeline and model registry.
- Added tests, Docker support, CI, data provenance, model card and runbooks.
- Preserved public source snapshots and cleaned datasets.
- Included academic report, presentation and viva guide as supporting materials.
